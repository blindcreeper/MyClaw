name: 天气查询
description: "查询全球任意城市的实时天气和未来预报。基于 Open-Meteo 免费 API，无需 API Key。"

## 🧠 智能体使用说明

### 适用场景
- 用户问"今天天气怎么样"、"明天会下雨吗"
- 查询某个城市的温度、湿度、风速、天气状况
- 获取未来几天的天气预报
- 出行前查看目的地天气

### run 模式命令格式
```
python {baseDir}/weather.py <城市名>
python {baseDir}/weather.py <城市名> --days 5
python {baseDir}/weather.py <城市名> --json
```

### 参数说明
- `<城市名>`: 中文或英文城市名，如 `杭州`、`Beijing`、`Tokyo`、`New York`
- `--days N`: 预报天数（1-7），默认 3
- `--json`: JSON 格式输出

### 示例
```
python {baseDir}/weather.py 杭州
python {baseDir}/weather.py "San Francisco" --days 5
python {baseDir}/weather.py 东京 --json
```

### 天气代码速查
| 代码 | 含义 | emoji |
|------|------|-------|
| 0 | 晴天 | ☀ |
| 1-3 | 多云 | ⛅🌤☁ |
| 45,48 | 雾霾 | 🌫 |
| 51-57 | 毛毛雨 | 🌦 |
| 61-67 | 雨 | 🌧 |
| 71-77 | 雪 | ❄ |
| 80-82 | 阵雨 | ⛈ |
| 95-99 | 雷暴 | ⚡ |

### 注意事项
1. 数据来源 Open-Meteo，免费无需 API Key，每分钟最多 600 次请求
2. 城市名支持中英文，底层自动地理编码
3. 如果城市名不明确（如多个同名城市），会返回最佳匹配
